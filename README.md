# Customer Churn Prediction

## 1. Project Overview
Customer Churn Prediction is a machine learning project that predicts whether a customer is likely to leave a service.

## 2. Project Objective
The main objective is to identify customers who may stop using the service and help businesses take steps to improve customer retention.

## 3. Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Matplotlib
- Joblib

## 4. Project Methodology
1. Data collection
2. Data cleaning and preprocessing
3. Exploratory data analysis
4. Model training
5. Model evaluation and comparison
6. Final model selection
7. Prediction pipeline development
8. Streamlit application development

## 5. Project Features
- Customer churn prediction
- Interactive Streamlit application
- Customer churn analysis charts
- Input validation
- Prediction results with explanations

## 6. Installation and Setup

Install the required libraries:

```bash
pip install -r requirements.txt
```

## 7. How to Run the Application

Open the project folder in VS Code and run:

```bash
python -m streamlit run app.py
```

The application will open in your browser.

## 8. Model Information
The project uses a trained machine learning model saved in the models folder. The prediction pipeline handles preprocessing and generates churn predictions.

## 9. Limitations
- Predictions depend on the quality of the dataset.
- Model predictions are estimates and are not guaranteed to be correct.
- The application is intended as a project demonstration.

## 10. Conclusion
This project demonstrates how machine learning can help businesses identify customers who may leave their services and support better customer retention decisions.
